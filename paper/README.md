# paper/

Working draft of the Slitherlink tool-granularity / Goldilocks paper.

## Layout

- `main.tex` — the paper source (article-class for now ; swap preamble
  for the AAAI / FLAIRS / workshop template before submission).
- `references.bib` — bibliography (22 arXiv entries + Yato & Seta 2003,
  generated 2026-05-25 via `math-search` MCP `arxiv_get`).
- `figures/` — PNGs regenerated by
  `python -m harness.analyze_phase2 --figures`. Do not edit by hand.
- `main.pdf` — compiled output. Tracked for convenience ; auxiliary
  `.aux/.bbl/.log/.out` files are gitignored.
- `build.sh` — one-shot compile.

## Building

```
bash paper/build.sh
```

(or, from the repo root:
`latexmk -pdf -cd paper/main.tex`).

Toolchain: TeX Live 2025 or newer. The build runs `pdflatex + biber`
via latexmk and produces `main.pdf` (~14 pages at this draft stage).

## Regenerating figures

If `harness/results/*.json` change (a new trial lands, an existing
trial is reclassified), refresh the figures and tables before
compiling:

```
.venv/bin/python -m harness.analyze_phase2 --figures
bash paper/build.sh
```

The analyzer prints the per-puzzle tables and prediction verdicts
that §5 of the paper reports. Numbers in `main.tex` are
hand-transcribed from that output ; cross-check after any data
change.

## Source-of-truth note

`main.tex` is the canonical version of the paper. An earlier
markdown draft (`main.md`) was the working format through 2026-05-24
and is preserved in git history (commits `6813776`, `d9019ad`) ; it
has been removed from the tree since the LaTeX form supersedes it.
